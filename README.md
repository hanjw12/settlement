# N빵 정산기

여러 명이 함께 쓴 금액을 건별로 나눠 정산하는 단일 HTML 웹앱입니다.

## 사용법

1. 참여자 이름 등록 (쉼표로 여러 명 한 번에)
2. 사용 금액 건마다 내용·금액·결제자 입력
3. 건별로 나눌 사람을 이름 칩을 눌러 선택 (기본 전원)
4. 누가 누구에게 얼마를 보내면 되는지 자동 계산 → 결과 복사

여러 정산을 저장해 두고 전환할 수 있고, **링크 공유**로 다른 사람에게 정산 내용을 보낼 수 있습니다.

## 데이터와 개인정보

- 서버가 없습니다. 입력한 내용은 사용하는 브라우저(localStorage)에만 저장됩니다.
- 공유 링크는 정산 내용을 압축해 URL `#` 뒤에 담습니다. 암호화가 아니므로 링크를 가진 누구나 내용을 볼 수 있습니다. 실명·계좌번호 같은 민감한 정보는 넣지 마세요.
- 공용 PC에서 사용했다면 "삭제" 버튼으로 정산을 지워 주세요.
