# N빵 정산기

여러 명이 함께 쓴 금액을 건별로 나눠 정산하는 단일 HTML 웹앱입니다.

## 사용법

1. 참여자 이름 등록 (쉼표로 여러 명 한 번에)
2. 사용 금액 건마다 내용·금액·결제자 입력
3. 건별로 나눌 사람을 이름 칩을 눌러 선택 (기본 전원)
4. 누가 누구에게 얼마를 보내면 되는지 자동 계산 → 결과 복사

여러 정산을 저장해 두고 전환할 수 있고, **링크 공유**로 다른 사람에게 정산 내용을 보낼 수 있습니다.

## 공유 방식 두 가지

| | 링크 공유 (기존) | 실시간 공유 |
|---|---|---|
| 저장 위치 | 각자 브라우저 | Supabase 공유방 + 각자 브라우저 사본 |
| 함께 수정 | 안 됨 (보낸 시점의 내용) | 됨 (약 3초마다 반영) |
| 링크 형태 | `#s=...` | `#r=...` |

실시간 공유를 시작하면 정산이 공유방으로 올라가고, 링크를 받은 사람은 같은 공유방을 열어 함께 수정합니다.
같은 건을 동시에 고치면 나중에 저장한 쪽이 남습니다.

### 실시간 공유 설정

1. Supabase 대시보드 > SQL Editor 에서 [`supabase/schema.sql`](supabase/schema.sql) 을 실행합니다.
2. `index.html` 의 `SUPABASE_URL`, `SUPABASE_KEY` 에 프로젝트 URL과 공개(publishable/anon) 키를 넣습니다.
   **service_role / secret 키는 절대 넣지 마세요.**
3. 같은 파일 CSP 메타 태그의 `connect-src` 를 프로젝트 URL로 맞춥니다.

공유방은 추측할 수 없는 22자 난수 ID로 구분되며, 데이터베이스 정책(RLS)이 요청에 담긴 방 ID와 일치하는 행만 허용합니다.
링크(방 ID)를 가진 사람은 누구나 그 정산을 읽고 고칠 수 있습니다.

### 롤백

- `SUPABASE_URL`, `SUPABASE_KEY` 를 비우면 실시간 기능이 숨겨지고 기존 방식만 동작합니다. 각자 브라우저에 마지막으로 받은 내용은 일반 정산으로 남습니다.
- 실시간 기능 도입 전 버전은 `v1-local` 태그로 남아 있습니다.

## 데이터와 개인정보

- 링크 공유만 쓰면 서버가 없습니다. 입력한 내용은 사용하는 브라우저(localStorage)에만 저장됩니다.
- 실시간 공유를 쓰면 그 정산의 제목·이름·항목·금액이 Supabase에 저장됩니다. 필요 없어진 공유방은 Supabase 대시보드에서 지울 수 있습니다.
- 공유 링크는 정산 내용을 압축해 URL `#` 뒤에 담습니다. 암호화가 아니므로 링크를 가진 누구나 내용을 볼 수 있습니다. 실명·계좌번호 같은 민감한 정보는 넣지 마세요.
- 공용 PC에서 사용했다면 "삭제" 버튼으로 정산을 지워 주세요.
